# Run Near Me

Run Near Me is a UK running-event discovery application.

## Repository role

This public repository is the source of truth for application code. The accepted application baseline before this documentation-only change is `4cb0f2280a3b8a8e5a904b2a2056ae72dc037ed9`.

Operational governance, production audit evidence and private provenance records are maintained outside this public repository. They are intentionally not mirrored here.

The files under [`docs/renm/`](docs/renm/README.md) are retained only as public development context. They must not be treated as the current operational authority.

## Current delivery state

The bounded outbound-wayfinding pilot and its first quality-of-life package are complete. Further data work starts with read-only evidence and separately approved, reversible packages.

Nothing in this repository's documentation independently authorises production-data, schema or deployment changes.
