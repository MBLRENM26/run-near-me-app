# RENM public documentation

This directory contains public development snapshots created during earlier phases of Run Near Me.

These documents are not the current operational governance set. The live governance kernel, decision register, production audit evidence, private provenance and exact database-operation records are maintained in a separate private control-plane workspace.

For repository work:

- Application code and commit history here remain authoritative for implementation.
- Dated files here are historical context unless a task explicitly identifies one.
- Do not infer approval for production data, schema, deployment or external-contact actions from these snapshots.
- Do not copy private control-plane documents into this public repository.

Current public status: the bounded outbound-wayfinding pilot and QL1 event-page information improvements are complete. QL2 begins read-only and requires separate approval before any production mutation.
