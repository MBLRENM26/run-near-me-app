
- Month listing pages compute their counts through `src/lib/month-summary.ts` (pure, tested); reuse it for any other "what is on when" surface instead of recounting — keeps every count consistent and data-only.
- Monthly host-club links use a private server reader and pure resolver requiring accepted verified organising links and unique approved crosswalks; only public club names/slugs and eligible event IDs leave the server, to avoid leaking identity evidence or turning candidate matches into public claims.
- Rich race research is stored in private append-only assertions and review audit tables, with file-hash idempotency and no event projection; keep it separate from monitor payloads because researcher confidence, occurrence identity and human acceptance are distinct.
- Rich race-research review is exception-only: `src/lib/research-auto-review.ts` (pure, tested) decides auto-accept vs needs-review; auto acceptances are append-only review rows tagged with a rule version so a whole rule can be revoked — keeps the admin from re-doing verified research while staying reversible.
- Scottish event-page fetches use the tested bounded retry helper in `src/lib/scottish-request-retry.ts`; retry only transient read failures, never replay database writes, to recover safely from provider timeouts.
- App email feature helpers call the managed template sender through an append-only receipt adapter; retained legacy email tables are audit-only, never suppression gates, so delivery remains platform-owned and notification failure cannot block the triggering feature.

- Research monitoring keeps the raw backlog count and uses the separately versioned verified-support workload only when a new worker policy explicitly opts in; signed v2 controls bind an exact source set and fail closed on incomplete controls. See docs/renm/RENM-monitor-operations-2026-11-05.md.
- Coverage reports are private, daily-idempotent snapshots plus weekly allowlisted calendar leads; never project leads into event facts, and expire the approved trial rather than silently expanding the old monitor.
- Public accepted race details include same-date reviewed duplicate aliases, selecting the newest accepted field without moving or rewriting append-only evidence; redirects must not discard accepted facts.
